# Security and sensitive data

Do not open a public issue containing statements, customer identifiers, account references, credentials or private recipient names.

For vulnerabilities or accidental sensitive-data disclosure, use [GitHub private vulnerability reporting](https://github.com/DouwJacobs/sente-config/security/advisories/new). Include only the minimum redacted details and affected file/commit; do not upload a real financial export. If private reporting is unavailable, remove sensitive details and ask the maintainer for a private contact route.

The maintainer will investigate, coordinate a fix and respond as capacity permits. No fixed response time is promised. Only the current main configuration format is maintained; pin known-compatible tags/commits and inspect Sente's import preview before applying updates.
